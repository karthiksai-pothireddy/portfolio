# Karthik Pothireddy — Portfolio

Personal portfolio built with React, TypeScript, Tailwind CSS and Framer Motion.

- Interactive hero: the cadet's head follows your cursor; press **PUSH ME** for the helmet.
- About, Skills, Experience (Verizon, Discover, CRED), Projects and Contact sections.
- Resume download at `/Karthik_Pothireddy_Resume.pdf`.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build` (output in `dist/`).

Content lives in `src/data.ts`; links (email, LinkedIn, resume) are in `src/components/Buttons.tsx`.
